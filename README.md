A one-liner entry for the make.fun debugging haiku competition: a 5-7-5 haiku
about the loneliest hour of a debugging session — 3 a.m., the cursor blinking,
the screenlight on your face, and the code you swear you never touched.

## The haiku

> Cursor blinks at three
> a.m., screenlight on my face
> I changed not one thing

## How to run

```sh
node main.ts
```

This writes the haiku to `/output/entry.txt` (three lines, no trailing
newline) and prints it to stdout. No dependencies — Node 22 only.

## Why this haiku

The first two lines set one concrete picture: a lone programmer at 3 a.m.,
lit only by the screen. The last line turns it — the bug appeared anyway,
and nothing was changed. Every word earns its place; nothing extra remains.
